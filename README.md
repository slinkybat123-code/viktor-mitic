# Viktor Mitic website

Live at https://slinkybat123-code.github.io/viktor-mitic/

A static site: 14 pages generated by a small Python program (standard library only),
published by GitHub Actions to GitHub Pages. Everything the pages load (pictures, 3D
frames, fonts, styles, script) is stored in this repository.

## Where things are

| Path | What it is |
|---|---|
| `build.py` | Builds the whole site into `_site/` (not committed). |
| `check.py` | Checks the built site; publishing stops if it fails. |
| `sitegen/config.py` | Web address, folders, navigation, security policy. |
| `sitegen/content.py` | Shared tables: captions, videos, articles, films, 3D viewer settings. |
| `sitegen/pages/` | One file per area of the site; the page text lives here. `news.py` holds the News list. |
| `sitegen/parts.py`, `sitegen/layout.py` | Building blocks and the frame around every page. |
| `sitegen/meta.py` | Search and sharing tags, `sitemap.xml`, `robots.txt`. |
| `data/site.json` | The picture lists for each gallery. |
| `assets/` | `site.css`, `site.js` and the two fonts. |
| `img/u/`, `img/v/` | Pictures, from the old artorwar.com site and the artist's second site. |
| `img/3d/sc1` … `sc5` | Frames of the five 3D turntables (WebP). |
| `.github/workflows/site.yml` | Build, check and publish on every push to `main`. |
| `SECURITY.md` | How the site is protected and how to report a problem. |

## Changing something

1. Edit the text in `sitegen/pages/` (for news, add an item at the top of `NEWS` in `news.py`).
2. Run `python build.py`, then `python check.py`.
3. To look at it: `python -m http.server 8000 --directory _site` and open http://localhost:8000.
4. Commit and push to `main`. GitHub builds, checks and publishes in about a minute.

Commit messages follow Conventional Commits (`feat: …`, `fix: …`, `chore: …`).

## Adding a picture

Put the file under `img/u/<year>/<month>/` and add it to the right list in `data/site.json`
with its width and height. Remove camera data (EXIF/GPS) from phone photos first.

## Moving to a custom domain

Set `SITE_URL` in `sitegen/config.py`, push, then add the domain under
the repository's Settings → Pages.
